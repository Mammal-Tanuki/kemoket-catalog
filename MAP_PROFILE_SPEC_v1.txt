けもケット会場マップ定義 v1
==========================

このファイルは設計仕様です。v12R6には実際の配置座標を同梱していません。

■ 基本方針
AI等でイベントごとの会場図を一度解析し、解析結果を map profile JSON に変換します。
PWA本体はAI解析を行わず、読み込んだJSONを使って画像上へ色付きSVGレイヤーを重ねます。

■ views[]
id     : 画面内の識別子
label  : 「全体」「左半分」「右半分」等の表示名
src    : マップ画像URL
width  : 元画像の横幅px
height : 元画像の縦幅px

■ spots[]
1つの配置番号を、1つのview上で示す矩形です。
同じ配置番号を全体図と詳細図の双方に登録する場合は、spotsを2件作成します。

例:
{
  "space": "A-01",
  "viewId": "right",
  "x": 0.8125,
  "y": 0.2333,
  "w": 0.0180,
  "h": 0.0210
}

x / y / w / h は画像サイズに対する0〜1の正規化座標です。
そのため、画像をスマホ上で拡大縮小しても位置がずれません。

■ アプリ側の表示
・灰色以外のサークルを設定色で半透明着色
・チェックリストの色表示ON/OFFと連動
・灰色は着色しないがタップ可能
・番号領域をタップすると、配置 / サークル名 / 代表 / 色 / 確認 / 訪問 を表示
・「一覧で開く」で該当サークルへ移動
・全体 / 左半分 / 右半分等はviews[]から自動生成
・マップ定義はイベントごとに保存
・「同期内容を削除」や「チェック初期化」ではマップ定義を削除しない
・イベント削除時のみマップ定義も削除
・通常バックアップにはマップ定義も含める
